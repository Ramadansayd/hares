# حارس (Hares)

## تشغيل
```
flutter create .        # مرة واحدة لتوليد مجلدات android/ios
flutter pub get
flutter run
```
- الشعار: حطه في `assets/images/logo.png`
- الأزرار بتصميمك: حط صورها في `assets/images/` وفعّل سطر `imageAsset:` في `home_screen.dart`
- البيانات: `assets/data/meetings.json` (صفحات 1–11) و `assets/data/daily.json` (366 قراءة)
